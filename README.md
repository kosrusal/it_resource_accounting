# it_resource_accounting

Учебный проект: система учёта IT-ресурсов — физических (ноутбуки, мониторы, серверы)
и облачных/логических (ВМ, базы данных, сервисы, лицензии, домены, сертификаты).

Пользовательский интерфейс для сотрудников, админский — для руководителя IT-отдела.
Заложены интеграция с таск-трекером, оповещения и графовое отображение зависимостей.

**Стадия: проектирование.** Кода пока нет — вся работа ведётся в документации.
