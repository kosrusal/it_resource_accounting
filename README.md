# it_resource_accounting

Учебный проект: система учёта ИТ-ресурсов — оборудования, виртуальных машин,
баз данных, сервисов, лицензий, доменов и сертификатов. Сотрудники работают
со своими ресурсами, ИТ-отдел ведёт реестр. Предусмотрены связь с внешней системой
задач, оповещения и граф зависимостей.

**Стадия: начальные требования и предварительное проектирование.** Кода приложения
пока нет. Основные документы подготовлены как начальные редакции;
согласование команды и испытания ПО ещё не проводились.

Начать с [указателя документации](docs/README.md). Основной пакет:

2. [План управления конфигурацией ПО](docs/configuration-management.md).

4. [Стандарт на разработку требований к ПО](docs/requirements-standard.md).

Раздел связи с системой задач входит в общие спецификации. Несогласованные параметры
и состояние подготовки документов перечислены в [открытых вопросах](docs/open-questions.md).
Проверка документов из корня репозитория в PowerShell 7: `pwsh -NoProfile -File scripts/check-docs.ps1`.
Она проверяет ссылки, номера и связи требований; поведение будущего приложения
эта команда не проверяет.
