# Материалы проекта

Текущий этап — постановка задачи, анализ готовых решений и подготовка докладов.
Предложения в документах обсуждаются командой; подробности реализации пока
предварительные. Для каждого блока определяются необходимые исходные данные,
порядок работы, результат и способ его проверки.

| Блок доклада | Основные материалы |
|---|---|
| Видение и предметная область | [01. Назначение](01-vision.md), [02. Предметная модель](02-domain-model.md) |
| Интеграции | [04. Внешние подключения](04-integrations.md), [08. Система задач](08-task-tracker.md) |
| Оповещения | [05. События, каналы и получатели](05-notifications.md) |
| Граф | [06. Представление и хранение графа](06-graph.md) |
| Регламентные работы | [07. Планирование обслуживания](07-maintenance.md) |
| Проверка и испытания | [10. Порядок проверки](10-testing.md) |

Дополнительные заметки: [03. Архитектура](03-architecture.md),
[09. Наблюдаемость](09-observability.md), [перечень будущих задач](backlog.md),
[открытые вопросы](open-questions.md). Оценки задач относятся к будущей реализации,
а не к объёму текущего доклада.

Подробные спецификации, планы и стандарт сохранены в отдельной ветке
[`codex/requirements-draft`](https://github.com/kosrusal/it_resource_accounting/tree/codex/requirements-draft).
Вернуться к ним можно после обсуждения границ и выбора решений. Приложения пока нет.
