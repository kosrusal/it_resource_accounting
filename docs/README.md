# Учёт ИТ-ресурсов — документация

Учебный проект: система учёта ИТ-ресурсов организации — физических (ноутбуки, мониторы,
серверы, периферия) и облачных/логических (виртуальные машины, БД, сервисы, лицензии,
домены, сертификаты).

Документация разделяет требования, предметные правила и проектные решения.
Технологии выбираются отдельно, до реализации соответствующих компонентов.
Идентификаторы требований сохраняются при изменении редакции.

## Статус

Стадия: **начальные требования и предварительное проектирование**. Приложения нет.
Документы не утверждены; вопросы, влияющие на выбранное приращение, закрываются
до перехода к его реализации. Описанные сценарии приёмки ещё не выполнялись.

Проверка оформления в PowerShell 7: `pwsh -NoProfile -File scripts/check-docs.ps1` из корня
репозитория. Смысловое рассмотрение требований проводится по стандарту отдельно.
