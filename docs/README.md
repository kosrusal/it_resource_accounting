# Учёт IT-ресурсов — документация

Учебный проект: система учёта IT-ресурсов организации — физических (ноутбуки, мониторы,
серверы, периферия) и облачных/логических (виртуальные машины, БД, сервисы, лицензии,
домены, сертификаты).

Документация написана **стек-агностично**: описывает предметную область, требования и
архитектурные границы, но не фиксирует язык/фреймворк. Выбор технологий — отдельное
решение на этапе старта реализации (см. `03-architecture.md`, раздел «Открытые вопросы»).
