## 1. Проблема заказчика

Права сотрудника настроены отдельно в каждом сервисе. Чтобы узнать, куда у сотрудника есть доступ, нужно по очереди зайти в Redmine, SVN, Git, домен Active Directory, на файловый сервер, в Яндекс; сейчас это час работы. Заказчик хочет видеть права в одном месте и, при возможности, управлять ими: минимум — сбор сведений, максимум — управление.

## 2. Бизнес-требования

| Номер | Требование | Источник |
|---|---|---|
| БТ-ПРВ-01 | Система должна позволять руководителю ИТ-отдела и специалисту ИТ-отдела выбрать сотрудника и увидеть сервисы, в которых у него есть доступ | З-11 |
| БТ-ПРВ-02 | Система должна позволять руководителю ИТ-отдела и специалисту ИТ-отдела увидеть права выбранного сотрудника в выбранном сервисе | З-11 |
| БТ-ПРВ-03 | Система должна позволять специалисту ИТ-отдела получить перечень сотрудников, имеющих доступ к выбранному сервису | Производное: нужно для З-15 (ПЗ-УВД) |
| БТ-ПРВ-04 | Система должна позволять специалисту ИТ-отдела изменить права сотрудника в выбранном сервисе | З-16 |
| БТ-ПРВ-05 | Система должна позволять администратору системы создать роль | З-12 |
| БТ-ПРВ-06 | Система должна позволять администратору системы задать роли право «чтение» или «изменение» на сведения выбранного сервиса | З-12 |
| БТ-ПРВ-07 | Система должна позволять администратору системы назначить роль сотруднику | З-12 |
| БТ-ПРВ-08 | Система должна позволять администратору системы отозвать роль у сотрудника | З-12 |
| БТ-ПРВ-09 | Система должна позволять администратору системы делегировать руководителю проекта право назначать выбранную роль сотрудникам его проекта | З-12 |
| БТ-ПРВ-10 | Система должна позволять руководителю проекта назначить делегированную ему роль сотруднику своего проекта | З-12 |

## 3. Границы

Входит: сервисы заказчика из раздела 1; роли и права «чтение», «изменение» в самой системе; делегирование руководителям проектов. Администратор системы отвечает только за выдачу прав и ролей (24.10).

Не входит: отдельный сотрудник для ведения прав (24.10).

Смежное: перечень сотрудников по БТ-ПРВ-03 использует ПЗ-УВД; отметка «только для ИТ-отдела» — ПЗ-БЗ, роли для неё берутся отсюда.

## 5. Вопросы к заказчику

1. Нужно ли в первой версии только видеть права или также изменять их в сервисах?
2. Какие права в каждом сервисе показывать: членство в группах, доступ к каталогам, роли в проектах?
3. Кроме Яндекс Почты, учитывать ли права в других сервисах Яндекса?
4. По каким сведениям определять, что сотрудник относится к проекту?
