## 1. Проблема заказчика

Для пользователя сервис — адрес, по которому он работает. Для специалиста ИТ-отдела сервис — несколько серверов, лицензия и другие составляющие. Чтобы перезагрузить сервер, специалист должен понять, на какие сервисы это повлияет, и уведомить их пользователей, что сервис будет недоступен на время работы (26.09 01:49).

## 2. Бизнес-требования

| Номер | Требование | Источник |
|---|---|---|
| БТ-УВД-01 | Система должна позволять специалисту ИТ-отдела увидеть сервисы, которые затронет выбранная работа | З-15 |
| БТ-УВД-02 | Система должна позволять специалисту ИТ-отдела увидеть пользователей затронутых сервисов | З-15 |
| БТ-УВД-03 | Система должна позволять специалисту ИТ-отдела уведомить пользователей затронутых сервисов о недоступности сервиса на время работы | З-15 |

## 3. Границы

Входит: определение затронутых сервисов и их пользователей, уведомление о недоступности на время работы. Способ доставки уведомления не выбран, это вопрос 1.

Не входит: оповещение через мессенджеры (решение заказчика, 10.10 30:45); служба приёма обращений.

Смежное:
- затронутые сервисы определяет БТ-УЧ-15 ПЗ-УЧ по связям сервиса с оборудованием (БТ-УЧ-13, З-08);
- время работы берётся из планового периода БТ-РР-04 ПЗ-РР; перенос (БТ-РР-06), отмена (БТ-РР-07) и завершение (БТ-РР-08) меняют период и состояние работы там же;
- пользователей сервиса определяет БТ-ПРВ-03 ПЗ-ПРВ (перечень сотрудников с доступом к выбранному сервису).
