## 2. Заказчик и проблема

### 2.1. Заказчик

Руководитель ИТ-отдела предприятия по ремонту авиационного оборудования. К нему обращаются руководство и бухгалтерия с вопросами о ресурсах (26.09; 24.10).

### 2.2. Проблема

1. Сведения о ресурсах, выдаче оборудования, сервисах и правах разнесены по таблицам и записям, например таблица на сорок вкладок (10.10).
2. Ответ на вопрос о правах сотрудника занимает около часа: нужно открыть каждый сервис по очереди (10.10). Бухгалтерия спрашивает, сколько ноутбуков и у кого (26.09).
3. База знаний — около 400 статей из личного опыта; навигация по ним держится на памяти автора и неудобна (24.10).
4. Сведения сами не наполняются и после ежегодного обхода не совпадают с фактом (24.10).
5. Пользователь видит сервис как рабочий инструмент с инструкцией, ИТ-отдел — как сервис, который нужно обслуживать (24.10).

## 6. Термины

| Термин | Значение |
|---|---|
| Ресурс | Учитываемый объект ИТ-отдела: оборудование или сервис. Сервис, оборудование, системное ПО и настройки — уровни просмотра сведений о ресурсе в статьях ПЗ-БЗ (10.10), а не виды ресурса |
| Сервис | Рабочий инструмент предприятия: оборудование, ПО, протокол и база данных (24.10) |
| Оборудование | Физическое устройство, учитываемое записью с идентификатором и типом; тип задаёт специалист ИТ-отдела (24.10); первоочередные виды — серверное, рабочие станции, сетевое (24.10), перечень не закрытый, поэтому монитор из З-17 тоже учитывается |
| Рабочее место | Место, где работает сотрудник; тип места (основное, лабораторное) определяет, какой компьютер на нём устанавливается (24.10) |
| База знаний | Статьи о том, что делать в определённой ситуации (24.10) |
| Работа по обслуживанию | Действие над ресурсом по пошаговой процедуре (24.10) |
