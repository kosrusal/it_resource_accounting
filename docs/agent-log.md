# Журнал агентов

Рабочий материал команды, не управляемый документ. Показывает, какой ИИ-агент что
подготовил в ветке `master`, чтобы каждый участник знал, за что отвечает и что
проверить. Каждый агент играл роль одного участника; фиксации в git подписаны
строкой «Агент: …».

## 3. Что осталось участникам

1. Прочитать итоговую редакцию своего раздела и протокол к нему.
2. Инспектору и ведущему — поставить подпись в итоговом протоколе (ПФИ, раздел 4).
3. После подписей автору — перевести раздел в версию 1.0, состояние «Принят», и добавить
   строку листа изменений «1.0 | <автор> | Принят по протоколу ПИ-<КОД>-NN» (ПФИ, раздел 5).
4. Исполнителю — подписать отчёты АП-01 и АП-02.
5. Завести в GitHub Issues сообщения о проблемах по замечаниям протоколов, если команда решит их регистрировать задним числом.
