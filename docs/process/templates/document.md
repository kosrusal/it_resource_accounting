# Шаблон документа

| Реквизит | Значение |
|---|---|
| Обозначение | Ш-ДОК |
| Версия | 1.0 |
| Состояние | Действует |
| Автор | Курышкин Иван |
| Категория контроля | КК2 |

## 1. Применение

Автор копирует нужную заготовку в файл с именем по [стандарту](../document-standard.md), заменяет подсказки в угловых скобках и удаляет лишнее. Подсказки в готовом документе не остаются.

## 2. Шаблон документа

````markdown
# <Название документа>

| Реквизит | Значение |
|---|---|
| Обозначение | <обозначение по таблице стандарта> |
| Версия | <0.1 для первой редакции> |
| Состояние | <Черновик | Принят | Действует> |
| Автор | <Фамилия Имя> |
| Категория контроля | <КК1 | КК2> |

## 1. <Название раздела>

<Текст раздела.>

### 1.1. <Название подраздела>

<Текст подраздела.>

## 2. <Название раздела>

| <Столбец 1> | <Столбец 2> |
|---|---|
| <Ячейка> | <Ячейка> |

## 3. Лист изменений

| Версия | Автор | Изменение |
|---|---|---|
| <0.1> | <Фамилия Имя> | <Первая редакция> |
````
