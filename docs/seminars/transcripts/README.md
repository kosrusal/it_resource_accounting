# Расшифровки семинаров

Редакция 0.1. Внутренний рабочий материал команды.

Автор: Богомолов Арсений.

## 1. Назначение

Каталог хранит полные расшифровки записей семинаров. Расшифровка нужна, чтобы проверить,
что именно сказано на семинаре, когда конспекта недостаточно. Расшифровки не являются
документами проекта, требованиями или правилами и не передаются как результат работы.

## 2. Правила пользования

1. На каталог и его файлы не ссылаться: ни в документах проекта, ни в правилах, ни в протоколах,
   задачах и запросах на объединение.
2. Источник сведений — семинар по дате: «семинар 24.10». Путь к файлу, имя файла и время записи
   не указывать.
3. Сказанное на семинаре не цитировать дословно, а передавать пересказом.
4. Вывод из расшифровки переносится в документ направления или в правила; основанием служит
   семинар, а не расшифровка.
5. Расшифровки не изменяются. Новая расшифровка — новый файл.

## 3. Состав

Расшифровка семинара N лежит в `semN/ГГГГ-ММ-ДД_семинар_расшифровка.md`; N — номер семинара по порядку.

| N | Семинар |
|---|---|
| 1 | 26.09.2026 |
| 2 | 10.10.2026 |
| 3 | 24.10.2026 |
| 4 | 07.11.2026 |

В начале каждой расшифровки указаны длительность записи, способ получения и обозначения
говорящих. Метки вида `[12:07]` — время в записи.
