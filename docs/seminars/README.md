# Итоги семинаров

Редакция 0.3. Проект.

Автор: Богомолов Арсений.

Каталог хранит конспекты семинаров по записям: замечания преподавателя, задания
команде и пожелания заказчика в изложении ведущего семинара. Конспекты — рабочий
материал команды: они показывают, что нужно сделать и в каком направлении двигается
проект. Требованиями и правилами они не являются.

## 1. Как ссылаться

1. Документы, протоколы, задачи и запросы на объединение ссылаются на семинар
   только по дате: «семинар 24.10», «по замечанию семинара 10.10». Путь и имя файла,
   время записи и дословные цитаты не указываются; сказанное передаётся пересказом.
2. Вывод семинара переносится в соответствующий раздел направления или правил;
   ссылка на семинар указывает источник этого вывода.
3. На стандарты и лекции ссылаются по обозначению и разделу: «КТ-178С, раздел 5.1».
   Файлы стандартов и лекций в хранилище не хранятся.

Конспект семинара N лежит в `semN/ГГГГ-ММ-ДД_семинар_итоги.md`; N — номер семинара
по порядку. Конспекты перенесены без изменений. Метки вида `[12:07]` — время в записи
семинара; в документы они не переносятся. Записи в хранилище не хранятся, поэтому
ссылки на них и на внешние каталоги внутри конспектов не открываются.
