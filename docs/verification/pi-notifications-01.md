## 4. Заключение

Заключение: доработать.

Принять — все ответы «да». Доработать — есть хотя бы один ответ «нет». В предварительном протоколе заключение решения о принятии не содержит.

Предварительный протокол решения о принятии не содержит (ПФИ, раздел 7). Сообщения о проблемах в Issues регистрируются по замечаниям этого протокола.
