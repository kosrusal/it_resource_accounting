## 3. Замечания

| № | Место | Что не так | Что требуется |
|---|---|---|---|
| 1 | Разделы 1–5 (Ф-12) | Свободная ёмкость серверного оборудования названа также «свободными ресурсами» (строка 13), «серверными ресурсами» (строка 27), «свободным объёмом» ресурса (строка 21, БТ-МОЩ-03); в строке 45 (вопрос 4) свободная ёмкость названа «остатком ёмкости». Серверное оборудование в строке 43 (вопрос 2) названо «серверами». В строке 37 написано «собирает проверки доступности и производительности»: проверки выполняются, собираются их данные. В строке 38 «проверка для нового сервиса» не называет, что проверяется; в строке 37 то же названо «проверка, хватит ли ресурсов новому сервису» | По СОД 7: одна сущность называется одним словом во всём документе; слова употреблены в своём значении; формулировка однозначно называет объект проверки |
| 2 | Раздел 2, БТ-МОЩ-03, БТ-МОЩ-04 (Э-09) | По ПЗ, раздел 6, «ресурс» — учитываемый объект ИТ-отдела: оборудование или сервис; в З-06 «свободные ресурсы» — свободные компьютеры. В БТ-МОЩ-03 («свободный объём каждого учитываемого ресурса серверного оборудования») и БТ-МОЩ-04 («объём каждого ресурса, нужного новому сервису») слово употреблено в другом значении: величина серверного оборудования, измеряемая в единицах (вопрос 1). БТ-МОЩ-03 допускает два толкования: свободный объём каждой учтённой единицы серверного оборудования или каждой такой величины; БТ-МОЩ-04 — объём оборудования или сервиса, нужного новому сервису, или объём каждой такой величины | Каждое БТ допускает одно толкование; слова в БТ имеют значение, заданное ПЗ, раздел 6 (СТТ, раздел 5: однозначность) |
| 3 | Раздел 2, БТ-МОЩ-05 (Ф-17, Э-09) | Формулировка «получить ответ „хватает“ или „не хватает“ для нового сервиса» не называет, чего должно хватать и с чем сравнивается объём, указанный по БТ-МОЩ-04. Допустимы два толкования: сравнение с суммарным свободным объёмом всего серверного оборудования и сравнение со свободным объёмом одной единицы серверного оборудования; при одних и тех же данных они дают разные ответы | Условие требования названо явно, требование допускает одно толкование (СТТ, раздел 4, правило 2; раздел 5: однозначность) |
| 4 | Раздел 2, графа «Источник» БТ-МОЩ-04 (Э-12) | Записано «З-07; производное: нужно для БТ-МОЩ-05»: требование одновременно отнесено к задаче З-07 и помечено производным. По СТТ, раздел 7, и ТРМ, раздел 7, производное требование — требование без источника наверху. По записи нельзя установить, следует ли требование из З-07 | Графа «Источник» однозначно показывает, из какой задачи З-NN следует требование; пометку «производное» имеет только требование без источника наверху (СТТ, разделы 3, 7) |

Каждое замечание связано с ответом «нет». Для документа в состоянии «Черновик» протокол — единственная запись замечаний; для принятого документа (КК1) на каждое замечание заводится сообщение о проблеме, номер СП-NN указывается в основании.

## 4. Заключение

Заключение: доработать.

Принять — все ответы «да». Доработать — есть хотя бы один ответ «нет». В предварительном протоколе заключение решения о принятии не содержит.
